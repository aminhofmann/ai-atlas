## Intuition
BERT needs a different head for classification, tagging or question answering.
T5 says: make everything a translation problem. Input "translate English to
German: That is good." → output "Das ist gut." Input "cola sentence: The
course is jumping well." → output "unacceptable". One model, one loss, one
decoding procedure for every task.

Its pretraining game is a variant of fill-in-the-blanks: cut a few chunks out
of a sentence, replace each with a placeholder, and have the decoder write out
the missing chunks.

## Mechanics
**Architecture:** the original encoder-decoder Transformer with small changes:
- **Pre-norm** with a simplified LayerNorm (scale only, no bias or mean
  subtraction — essentially RMSNorm), no bias terms.
- **Relative position bias:** instead of absolute embeddings, a learned scalar
  added to attention logits per head, indexed by bucketed relative distance
  (log-spaced buckets), shared across layers.
- Sizes from Small (~60M) to **11B** parameters; SentencePiece vocabulary of 32k.

**Pretraining objective — span corruption:**
- Corrupt **15%** of tokens, in spans with **mean length 3**.
- Each dropped span is replaced in the input by a unique sentinel
  (`<extra_id_0>`, `<extra_id_1>`, …).
- The target is the sentinels followed by the dropped content, e.g.
  input `Thank you <X> me to your party <Y> week.` → target
  `<X> for inviting <Y> last <Z>`.
- Targets are short, so this is cheaper than reconstructing the whole input.

**Data:** **C4** (Colossal Clean Crawled Corpus), ~750 GB of filtered Common
Crawl English text, released with the paper.

**Training/inference:** teacher-forced cross-entropy on the target text; a task
prefix in the input tells the model what to do. Even regression (STS-B) is done
by emitting numbers as text.

**The paper as a study:** it systematically compared architectures
(encoder-decoder vs decoder-only vs prefix LM), objectives, corruption rates,
datasets and multi-task mixtures; encoder-decoder with a denoising objective
performed best in their setting.

**Descendants:** T5.1.1 (GEGLU FFN, no dropout during pretraining), mT5
(multilingual), ByT5 (byte-level), Flan-T5 (instruction-tuned).

## Code
```python
# Illustrative HuggingFace usage; task chosen purely by the text prefix.
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

tok = AutoTokenizer.from_pretrained("t5-small")
model = AutoModelForSeq2SeqLM.from_pretrained("t5-small")

for prompt in ["translate English to German: That is good.",
               "summarize: The quick brown fox jumped over the lazy dog "
               "because it was bored and wanted exercise."]:
    ids = tok(prompt, return_tensors="pt").input_ids
    print(tok.decode(model.generate(ids, max_new_tokens=20)[0],
                     skip_special_tokens=True))

# Span-corruption training pair:
src = tok("Thank you <extra_id_0> me to your party <extra_id_1> week.", return_tensors="pt")
tgt = tok("<extra_id_0> for inviting <extra_id_1> last <extra_id_2>", return_tensors="pt")
loss = model(input_ids=src.input_ids, labels=tgt.input_ids).loss
```

## Why it matters
T5 unified NLP tasks under one interface, which foreshadowed today's
prompt-and-generate usage of LLMs, and its paper is still a reference for
which pretraining choices matter. C4 became a standard pretraining dataset.
Encoder-decoder T5 variants remain popular where inputs are long and outputs
short (summarisation, translation, retrieval-augmented generation), and as text
encoders in some image-generation models.

## Self-test
Q: What does "text-to-text" mean in T5?
A: Every task, including classification and regression, is framed as generating an output string from an input string with a task prefix.

Q: Describe T5's span-corruption objective.
A: About 15% of tokens are dropped in spans (mean length 3), each replaced by a sentinel token; the decoder outputs the sentinels followed by the missing spans.

Q: How does T5 encode position?
A: With learned relative position biases added to attention logits, bucketed by relative distance.

Q: What is C4?
A: The Colossal Clean Crawled Corpus, a filtered Common Crawl English dataset released with T5.
